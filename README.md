# Smart Task Manager - Backend API

## Overview
REST API for tasks with authentication and database integration.  
Supports CRUD operations, secure login, and cloud deployment.

## Tech Stack
- Node.js / NestJS
- MongoDB or MySQL
- JWT Authentication
- Docker

## Setup
1. Clone this repo
2. Run `npm install`
3. Start server: `npm run start`
